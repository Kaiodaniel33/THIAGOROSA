# Projeto Web: Thiago Rosa | Mentoria Fitness

Este repositório apresenta a solução web desenvolvida para o profissional **Thiago Rosa**, especialista em treinamento físico e mentoria fitness de alta performance.

O projeto consiste em uma *landing page* corporativa criada com o objetivo de fortalecer a presença digital do cliente, consolidar sua autoridade profissional no mercado fitness e ampliar a captação de novos alunos para programas de consultoria presencial e online.

A interface foi desenvolvida seguindo padrões modernos de desenvolvimento Front-End, priorizando desempenho, sofisticação visual, responsividade e experiência do usuário. O design adota uma identidade contemporânea baseada na estética *Glassmorphism*, proporcionando uma apresentação visual elegante, moderna e alinhada ao posicionamento premium da marca.

---

# Tecnologias e Arquitetura Utilizadas

O ambiente foi estruturado utilizando tecnologias Front-End modernas e otimizadas para desempenho, organização e escalabilidade.

## HTML5

Utilizado para a construção da estrutura semântica da aplicação, garantindo melhor organização do conteúdo, acessibilidade e compatibilidade com navegadores modernos.

---

## Tailwind CSS

Framework utilitário empregado via CDN para estilização rápida e padronizada da interface.

Sua utilização permitiu:

* maior produtividade no desenvolvimento;
* organização visual consistente;
* responsividade eficiente;
* escalabilidade do código;
* alinhamento preciso dos componentes através do sistema de grid.

---

## CSS3 Customizado

Além do Tailwind CSS, foram implementadas estilizações personalizadas para reforçar a identidade visual exclusiva do projeto.

Entre os recursos aplicados, destacam-se:

* efeitos de *Glassmorphism* com transparência e desfoque;
* gradientes dinâmicos e iluminação suave;
* animações visuais de ambiente;
* tratamento visual das imagens para melhor nitidez e qualidade estética;
* transições suaves de interação.

---

## JavaScript (Vanilla ES6+)

Toda a interatividade da aplicação foi desenvolvida em JavaScript puro, sem dependência de bibliotecas externas pesadas.

Os principais recursos implementados incluem:

* controle do menu responsivo mobile;
* sistema interativo de FAQ em formato *accordion*;
* animações baseadas em rolagem da página (*Scroll Reveal*);
* manipulação dinâmica de elementos do DOM;
* utilização da API nativa `IntersectionObserver` para otimização de desempenho.

# Funcionalidades Implementadas

## Design Responsivo

A plataforma adapta automaticamente sua interface para diferentes tamanhos de tela, incluindo smartphones, tablets, notebooks e monitores de alta resolução.

Essa abordagem garante uma experiência de navegação consistente e profissional em qualquer dispositivo.

---

## Integração Direta com WhatsApp

Foram implementados botões estratégicos de chamada para ação (CTAs) integrados à API do WhatsApp.

O sistema direciona o usuário diretamente para o contato do cliente, preenchendo automaticamente mensagens relacionadas ao plano de consultoria desejado, otimizando o processo de conversão.

---

## Sistema FAQ Interativo

A aplicação possui uma seção de perguntas frequentes em formato expansível (*accordion*), desenvolvida para:

* organizar melhor as informações;
* reduzir objeções comerciais;
* melhorar a experiência do usuário;
* aumentar a retenção de visitantes na página.

---

## Animações de Rolagem (Scroll Reveal)

Os elementos visuais da interface são carregados progressivamente conforme o usuário navega pela página.

Essa técnica proporciona:

* maior dinamismo visual;
* melhor percepção de fluidez;
* otimização do carregamento;
* experiência mais moderna e interativa.

# Implantação e Execução do Projeto

O projeto foi estruturado como uma aplicação estática, dispensando instalação de dependências ou gerenciadores de pacotes.

## Passos para execução

1. Realize o clone do repositório:

```bash id="0jv9xw"
git clone [url-do-repositorio]
```

2. Acesse o diretório raiz do projeto.

3. Verifique a integridade dos arquivos localizados em `assets/img/`.

4. Execute o arquivo `index.html` em qualquer navegador moderno para visualização da aplicação.
